# ManifestCV Agent Prompts

These prompts cover ManifestCV-specific setup and workflows. They are owned by
ManifestCV and are not part of the Mystic Auth foundation.

## Available prompts

- [Set up ManifestCV for local development](manifestcv-setup.md): configure the
  paired runtime environment, start the Docker stack, verify the product, and
  preserve the Mystic Auth ownership boundary.

For the shared identity foundation's own setup and synchronization procedures,
see the prompts under [`agent-prompts/mystic_auth/`](../mystic_auth/README.md).
